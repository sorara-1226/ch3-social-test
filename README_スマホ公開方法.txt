# スマホ公開用ファイル

このフォルダの `index.html` が入口ページです。

## GitHub PagesでURLにする方法
1. GitHubにログイン
2. 新しいRepository（例：ch3-social-test）を作成
3. このフォルダ内のファイルをすべてアップロード
4. Repositoryの Settings → Pages
5. 「Deploy from a branch」を選択
6. Branchを `main`、フォルダを `/ (root)` にして Save
7. 数分後に表示されるURLをスマホで開く

入口は `index.html` です。

## QRコード
URLが発行されたら、そのURLをQRコード作成サイトに入力してQRコードを作成できます。
